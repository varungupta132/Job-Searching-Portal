# 🎯 Job Portal - Frontend Only

**Live Demo**: https://varungupta132.github.io/Job-Searching-Portal/

A beautiful, responsive job portal built with pure HTML, CSS, and JavaScript. No backend required!

## ✨ Features

- � **Job Search** - Search by title, company, or skills
- 🎯 **Smart Filters** - Filter by location, experience, and job type  
- 💼 **Job Details** - Click any job card for detailed view
- 🎨 **Animated UI** - Beautiful gradients and smooth animations
- � **Responsive Design** - Works perfectly on all devices
- ⚡ **Fast Loading** - Pure frontend, no API calls needed

## 🎨 Design Features

- **Animated Gradient Header** - Colors shift automatically
- **Glassmorphism Effects** - Translucent cards with blur effects  
- **Hover Animations** - Interactive job cards with smooth transitions
- **Modal Popups** - Detailed job information in elegant modals
- **Custom Animations** - Cards slide up on page load

## 🚀 Technologies Used

- **HTML5** - Semantic structure
- **CSS3** - Advanced styling with gradients, animations, and glassmorphism
- **JavaScript (ES6+)** - Modern vanilla JS, no frameworks needed

## 📊 Sample Data

Contains 12 sample job listings across various:
- **Locations**: Mumbai, Bangalore, Delhi, Pune, Hyderabad, Chennai
- **Experience Levels**: Fresher, Junior, Mid-level, Senior  
- **Job Types**: Full-time, Part-time, Contract, Internship
- **Industries**: Tech, Design, Marketing, Product Management

## 🎯 How to Use

1. **Search**: Type job title, company name, or skill in the search box
2. **Filter**: Use dropdowns to filter by location, experience, or job type
3. **Browse**: Click any job card to see full details
4. **Apply**: Click "Apply Now" for demo application flow

## 💻 Local Development

Simply open `index.html` in your browser - no build process needed!

```bash
# Clone the repository
git clone https://github.com/varungupta132/Job-Searching-Portal.git

# Navigate to project directory  
cd Job-Searching-Portal

# Open in browser
open index.html
```
